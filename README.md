# Ecotex Inc - Frontend

Client-side React 19 application built with Vite, TailwindCSS v4, Zustand, and Motion.

## Features
- B2B eCommerce Catalog for eco-friendly custom bags & packaging.
- Interactive Instant Quote Calculator with real-time volume pricing.
- Complete Administrator Dashboard (`/admin`) for product, quote, order, and media management.
- Dynamic cart drawer, search modal, and responsive navigation.

## Setup & Running
```bash
npm install
npm run dev
# Starts Vite development server at http://localhost:3000
```

> **Note:** The backend API server runs in `../ecotex-inc-backend` at `http://localhost:3001`. Vite dev server automatically proxies `/api` and `/uploads` requests to the backend.
